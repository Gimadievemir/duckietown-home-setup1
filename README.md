## Цель работы

Подготовить домашнюю среду для работы с Duckietown, установить необходимые инструменты и проверить их работоспособность.

## Используемые технологии

- Windows Subsystem for Linux (WSL2)
- Ubuntu 26.04.1 LTS
- Docker
- Duckietown Shell (DTS)
- Duckiematrix

## Выполненные работы

1. Проверена информация об операционной системе.
2. Проверена работа WSL2.
3. Установлен и проверен Docker.
4. Запущен тестовый контейнер `hello-world`.
5. Запущена Duckiematrix с картой `sandbox`.
6. Подготовлены скриншоты результатов.
