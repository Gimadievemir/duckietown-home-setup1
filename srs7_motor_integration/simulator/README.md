# Проект Wokwi

Публичный проект (скетч v2 + модель L298N): https://wokwi.com/projects/479948419202755585

В Wokwi нет штатных деталей L298N и DC-мотора, поэтому драйвер сделан как custom chip:

| Файл | Что это |
|---|---|
| `diagram.json` | Основная схема: HC-SR04, кнопка, 3 LED с резисторами 220 Ом, чип `chip-l298n` (IN1→D5, IN2→D6, ENA→D3, VCC→5V, GND→GND) |
| `diagram_echo_break_switch.json` | То же плюс переключатель в линии ECHO: им эхо обрывается на ходу (тест 7, замер задержки остановки) |
| `l298n.chip.c`, `l298n.chip.json` | Модель L298N + мотора: реализует таблицу истинности из даташита, измеряет duty и частоту ENA, рисует ротор и шкалу скорости, пишет лог в Chips Console |
| `serial_and_chip_log_excerpts.txt` | Строки Serial Monitor и Chips Console всех прогонов |

Как воспроизвести: открыть ссылку выше и нажать Start. Чтобы задать расстояние, кликнуть по HC-SR04. Лог мотора смотреть на вкладке **Chips console**. Цвет на экране чипа: серый — выбег/стоп, зелёный — вперёд, оранжевый — назад, красный — торможение.

Варианты для экспериментов (вносить по одному):
- Тест 8: в `motorForward()` поменять местами `HIGH`/`LOW` у IN1 и IN2.
- Неисправность 1: удалить строку `[ "drv:GND", "uno:GND.2", ... ]`.
- Неисправность 2: `ENA_PIN = 4` и в схеме `uno:3` → `uno:4`.
- Тест 7: взять `diagram_echo_break_switch.json` и щёлкнуть переключатель во время работы.
